# Mac용 베르바

Mac용 베르바 설치 파일을 받는 곳이에요. 설치 파일만 올라오고, 소스 코드는 따로 관리해요.

- 대상: Apple Silicon(M1 이상) Mac · macOS 14 이상
- 형식: Apple 공증(notarization)을 받은 .dmg
- 받는 곳: [Releases](https://github.com/iyk89/verba-mac/releases/latest)

첫 Mac 버전은 준비 중이에요. 올라오면 Releases에서 받으실 수 있어요.
Windows용 베르바와 자세한 안내는 [verbanote.app](https://verbanote.app)에 있어요.

# Verba for Mac

This is where Verba's Mac installers are published. Only the installers live here; the source code is kept separately.

- For: Apple Silicon Macs (M1 or later) · macOS 14 or later
- Format: a .dmg notarized by Apple
- Download: [Releases](https://github.com/iyk89/verba-mac/releases/latest)

The first Mac release is on its way. Once it's out, you'll find it under Releases.
Verba for Windows, and everything else, is at [verbanote.app](https://verbanote.app).
